# 个人衣柜

本地运行的个人服装库与搭配工具。把自己每件衣服拍下来、抠好图导入，
在画布上自由拼出搭配，再套到自己的全身照上预览效果。

**所有数据只存在你的电脑里，不联网、不上传。**

## 你需要准备什么

每件衣服准备 **三张透明背景的 PNG**：

| 顺序 | 内容 | 说明 |
|------|------|------|
| 1 | 正面照 | 衣服挂起来，正对着拍 |
| 2 | 侧面照 | 转 90°，从侧面拍 |
| 3 | 背面照 | 转 180°，从背面拍 |

拍好后，用 AI 抠图工具（即梦 / 通义 / 其他你顺手的）把三张都抠成
**透明背景**，导出 PNG，就可以导入程序了。

另外准备一张你自己的 **全身照**（正面站立），用于「上身预览」。

> 提示：照片里衣服的大小、位置尽量一致，程序会自动对齐，但拍得越规整效果越好。

## 怎么运行（开发阶段）

```bash
# 1. 确认 Python 3.11 可用
py -3.11 --version

# 2. 在项目目录创建虚拟环境
py -3.11 -m venv .venv
.venv/Scripts/python.exe -m pip install -r requirements.txt

# 3. 运行
.venv/Scripts/python.exe main.py
```

> 注意：电脑上默认的 `python` 是 3.8，**不要直接用它**，必须用 `.venv` 里的 3.11。

## 最终交付

打包后会得到一个 `个人衣柜.exe`，双击就能用。

## 常见问题

**Q：程序提示「这张图没有透明背景」**
A：说明这张 PNG 四周还有不透明的像素，回到抠图工具重新导出一次。

**Q：旋转的时候三张图对不齐**
A：三张照片里衣服的大小差别太大。重新拍时把衣服挂同一位置，相机高度不变。

**Q：换了新电脑怎么办**
A：把整个程序文件夹（含 `data/`）拷过去，双击 exe 即可。

**Q：数据会丢吗**
A：数据在 `data/wardrobe.db` 里。建议定期把 `data/` 复制一份到别的位置。
