## 三、已完成的功能

### 衣柜

- 导入衣服：三张 / 五张角度图（front / front45 / side / back135 / back），压缩为 WebP，原图备份
- 衣柜挂杆视图：
  - 按类别分杆：上衣、外套、下装、连衣裙
  - 鞋、包、配饰放底部隔板
  - 暖色衣柜内壁、木纹挂杆、两端端头
  - 静止显示侧面图，悬停 260ms 旋转展开正面
  - 悬停时放大 1.15 + 浮起阴影 + 层级置顶
  - 前后图片顶部对齐，衣架压住肩膀约 4px
  - 同类别杆内按住左右拖动排序，松手保存
  - 拖动靠近左右边缘时自动横向滚动
  - 悬停显示名称、类别、颜色
  - 鞋、包、配饰隔板悬停：单品轻轻抬起、浮起阴影，显示类别与颜色
- 添加衣服：
  - 关闭抽屉时暂存草稿（图片、名称、类别、颜色、季节、场合）
  - 重新打开可以继续填写，不需要重新上传
  - 支持从文件夹拖入图片，自动填入角度
- 筛选：类别、颜色、季节、场合；名称搜索
- 删除衣服：弹窗确认 → 移入回收站（软删除）
- 三个角度 / 五个角度的拖动旋转查看（单品详情页）
- 单角度微调：大小、上下、左右

### 搭配

- 空白画布 → 左侧衣柜点衣服加入
- 拖动、滚轮缩放、层次调整、Delete 删除
- 上下边缘裁切（塞衣角 / 藏下摆）
- 场景标签、名称自动保存
- 搭配库：真实画布预览、场景筛选、名称搜索，卡片悬停轻微放大
- 导出 1200×1600 PNG 到 `data/exports/`，自动打开文件夹
- 删除搭配 → 移入回收站

### 上身图（用户外部生成后上传）

- 每套搭配可上传 5 个角度的整套上身图
- 统一处理为 1200×1600 白底，原图备份
- 独立「上身展示」页：拖动旋转、角度点、逐角度微调
- 搭配库封面优先使用上身图，带「上身」角标

### 数据安全（重点）

- 衣服 / 搭配软删除，进回收站，图片不立即删除
- 回收站支持恢复 / 彻底删除
- 被删衣服在搭配中隐藏，恢复后回到原位置
- 启动时自动备份数据库（保留 7 份）
- 设置页「立即备份」打包整个 data 目录（保留 5 份）
- 设置页显示最近备份信息

### 交互

- 双击 F（1 秒内连按两次）返回上一页；输入框聚焦、弹窗打开时不触发
- 所有删除统一弹窗确认；Esc / 点遮罩取消

### 打包

- 单个 `个人衣柜.exe`，约 20MB
- 数据在 exe 同级 `data/`，整个文件夹拷走即可迁移

## 七、重要约定（不要违反）

1. **数据安全优先**：任何删除都走软删除 + 回收站，不要直接 `rmtree` 或 `DELETE` 用户数据。
2. **每次功能完成 → 测试 → commit → push**，提交信息用中文说明。
3. 前端不用框架、不用构建工具，经典 `<script>` + `window.App`。
4. 所有颜色 / 圆角 / 间距写在 `web/css/variables.css`。
5. 图片展示用 WebP，原始图保留在 `original/`。
6. 画布坐标归一化到 0~1。
7. 测试不要使用真实 `dist/data`，一律用临时数据目录。
8. 打包前先关闭正在运行的 exe，否则 PyInstaller 无法覆盖。
9. 用户是编程小白，所有说明用中文、给具体操作步骤。
