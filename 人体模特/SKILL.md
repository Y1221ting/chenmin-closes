# 3D 人体模特 · 豆包出图技能（基于本人真实形象）

## 核心原则

- **图片由用户在豆包里生成**，本 skill 负责：锁定形象 → 产出可直接复制的完整提示词 → 指导豆包操作 → 回传后校验一致性。
- 不要假装已经生成图片；不要索要 API Key。
- 提示词**必须完整、已填好形象特征、无占位符**，用户复制即可用。
- 本 skill 与 `garment-angles` 的区别：
  | | garment-angles | 本 skill |
  |---|---|---|
  | 主体 | 悬浮的衣服（人全部去掉） | 固定的 3D 人（衣服穿在身上） |
  | 用途 | 抠图入库、衣柜单品图 | 试衣效果、搭配预览 |
  | 一致性基准 | 正面单品图 | **模特基准图（定稿后锁死）** |

## 一、形象特征（从本人 13 张自拍提取，已固化，不要重述）

| 部位 | 真实特征 | 模特处理 |
|------|---------|---------|
| 眼镜 | 黑色粗框大框圆角眼镜，几乎每张都有 | ✅ **最强辨识，锁死** |
| 脸型 | 圆润娃娃脸 / 鹅蛋脸，脸颊饱满，下巴柔和 | ✅ 保留 |
| 肤色 | 白皙偏暖 | ✅ 固定 |
| 头发 | 黑色长直发及胸 + 齐刘海；偶尔单侧马尾 / 双马尾 | ✅ 保留，但**扎低双马尾垂背后** |
| 身材 | 纤细 petite、窄肩、腰线明显 | ✅ 锁死，别被宽松衣服带跑 |
| 表情 | 甜美微笑 | ⚠️ 改中性自然表情 |
| 配饰 | 发圈、发夹、项链、手表 | ❌ 全去掉 |
| 背景 | 灰瓷砖墙、绿色帆船挂画、绿植、镜子、手机 | ❌ 全去掉 |

⚠️ 13 张全是**镜子自拍，左右是反的**：单侧马尾 / 发夹位置不要照搬；脸基本对称影响不大。

完整的、必须逐字复制的人物描述见 `references/形象锁定块.md`。

## 二、三个必须先讲清的设计决策

1. **长发必须扎起来**：本人标志性长直发披在身前会盖住领口、肩线、门襟、下摆——而试衣恰恰要看这些。保留辨识度（眼镜 + 刘海 + 黑长发），但头发扎低双马尾垂在背后，肩颈锁骨领口完全露出。
2. **换脸是最大风险**：3D 生成每次重画脸。必须先做**一次模特基准图**定稿锁死，之后所有图都以它为参考图、人物描述逐字复制、一个字都不改、不再传别的自拍。
3. **皮克斯风 ≠ 像本人**：必然卡通化幼态化，只能做到「眼镜 + 圆脸 + 刘海 + 纤细身形」的神似。保持皮克斯风是为了和衣柜里已有的皮克斯单品图统一；若要更像本人需换半写实 3D 数字人，那衣柜全部单品图也要重做。
   > 诚实边界：AI 试衣图是**搭配示意图**，会美化身形、微调衣服细节，不能替代真实上身的版型 / 尺码判断。

## 三、两条路径

### 路径 A：一步尝鲜（30 秒看效果，牺牲一致性）
上传 1 张本人正面自拍 → 复制 `prompts/豆包提示词全集.md` 第 0 条 → 3:4 → 生成 4 张选 1。
适合先看看「3D 版的我」长什么样、风格对不对。

### 路径 B：正式流程（可复用，推荐）
1. **模特基准图**：上传 1 张正面自拍 → 第 0 条提示词 → 生成正面基准图，定稿后存为 `avatar_base_front.png`，**锁死不再重画**。
2. **其余四角度**：以正面基准图为参考图 → 依次第 1~4 条（左前 45° → 左侧面 → 左后 135° → 背面）。
3. **逐件试衣**：以「对应角度基准图」+「该衣服参考图」双图输入（豆包若只支持单图，用文字描述衣服，见全集第 5 条说明）→ 一次一个角度。
4. **整套搭配试衣**：在衣柜里把这套搭配导出成一张平铺 PNG，用它当参考图 2，按全集第 6 条生成整套穿上身的效果；同样一次一个角度。
5. 每个角度尺寸、模特大小、朝向、姿态保持一致。
6. 已生成的 `*_皮克斯风.png` 单品图可直接当「衣服参考图」，画风天然统一，也可直接用作整套搭配导出图里的单品。

## 四、固定要求（所有提示词已内置，无需用户改）

- 比例：竖版 **3:4**（1330×1773 或平台最接近竖版），全身入镜，头顶 / 脚底各留约 5% 空白。
- 背景：纯色浅灰 **#D9D9D9**，平整无渐变；**不要任何落地阴影 / 投影 / 接触暗影 / 灰色投影块**（贴边阴影后期切不干净）。
  > 用浅灰而非纯白：本人常穿米白 / 奶白 / 浅粉 / 冰蓝，纯白背景下浅色衣身会糊进背景。
- 风格：3D 皮克斯动画电影风格，Pixar / Disney 质感，圆润柔和，卡通渲染，非照片写实，简化布料纹理与褶皱，柔和次表面散射，电影级柔光。
- 基准图着装：中性浅灰无痕圆领长袖贴身打底 + 浅灰贴身打底长裤，纯色无图案无 logo，无皮肤裸露。
- 姿态：自然站立 A-pose，双臂微张约 15°、手掌放松、双脚并拢、身体直立不歪斜。

## 五、豆包操作步骤（告诉用户）

1. 打开豆包 →「图片生成 / 图像编辑」。
2. 上传指定的参考图（路径 A 传自拍；路径 B 第 2 步起传**已定稿的正面基准图**）。
3. 粘贴对应那条提示词（从 `prompts/豆包提示词全集.md` 整段复制）。
4. 比例选 **3:4**。
5. 一次生成 4 张，挑最像、最干净的一张，下载原图。
6. 五角度分别重复；**一次只做一个角度**，不要让 AI 一次出五个角度。
7. 全部下载后放进同一个文件夹，把路径告诉 Claude 做校验。

---

## 六、回传图片后

1. 检查五角度齐全、尺寸一致、人物长相 / 眼镜 / 刘海 / 身材 / 姿态五张完全一致。
2. 逐项对照 `references/避坑与自检.md` 的自检清单。
3. **要上传到衣柜的「上身图」，必须先抠成透明 PNG**：衣柜上传只把透明区域铺白，不会去掉浅灰背景；直接上传会留下灰色矩形。用 rembg / u2net 类 AI 抠图；**浅色衣物不要用亮度阈值抠图**，会把高光和绒毛删成白斑。
4. 命名：`avatar_base_{front|front45|side|back135|back}.png`、`tryon_{garment}_{front|front45|side|back135|back}.png`（英文文件名，避免预览面板编码问题）。
5. 基准图定稿后**不要覆盖**；要调整形象另存 v2，否则旧试衣图会和新模特对不上。
6. 整套搭配的上身图：先在衣柜导出搭配平铺图，按第 6 条生成 5 个角度，再逐角度抠透明底并上传。

## 八、常见问题

| 问题 | 处理 |
|------|------|
| 生成的还是真人照片 | 把【风格】整段提到提示词最前面；负向词加「照片写实、真实皮肤纹理」 |
| 换了张脸 / 眼镜不见了 | 只认一张定稿基准图；锁定块逐字复制；不要传多张自拍 |
| 头发盖住领口 | 强调「头发扎低双马尾垂在背后，肩颈锁骨领口完全露出」 |
| 穿羽绒服人就变胖 | 锁定块写死「纤细窄肩」，加「衣服贴合但不改变身材比例」 |
| 背景有阴影 / 渐变 | 强调「纯色浅灰 #D9D9D9，无落地阴影、无投影、无接触暗影」 |
| 手畸形 / 多出举手机的手 | 负向词加「多余手指、畸形手、举手机的手」 |
| 五角度大小不一致 | 每次都写「与正面基准图同一高度、同一大小、全身入镜」 |
| 上传衣柜后有灰色矩形 | 先抠成透明 PNG 再上传；衣柜只把透明区域铺白，不会去背 |
| 整套搭配少一件 / 多一件 | 用衣柜导出的整套搭配图当参考图 2，提示词写「不要遗漏、不要新增」 |
