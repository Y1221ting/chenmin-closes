# START-HERE · 用豆包生成第一张，30 秒上手

> 本目录只提交提示词文档；生成的 `avatar_base_*`、`tryon_*` 等图片已在 `.gitignore` 中排除，不会进 Git。

只想先看效果的话，**只做这一步**：

1. 打开豆包 →「图片生成 / 图像编辑」
2. 上传 **1 张本人正面自拍**（挑正脸、刘海和黑框眼镜都在、手臂没挡身体的一张）
3. 打开 `prompts/豆包提示词全集.md`，整段复制 **第 0 条**
4. 比例选 **3:4**
5. 生成 4 张，挑最像、最干净的一张，下载存为 `avatar_base_正面.png`

这张就是你的 **3D 试衣模特基准图**，后面所有角度和所有试衣都靠它锁住长相。

---

## 想直接试穿一件衣服？

复制 `prompts/豆包提示词全集.md` **第 5 条**（已填好「奶白双排扣长款大衣」），
上传刚生成的 `avatar_base_正面.png`，再把衣柜里的
`奶白双排扣长款大衣_正面_皮克斯风.png` 一起传上去（豆包支持多图时），
就能看到模特穿上这件大衣的效果。

换别的衣服：**只改第 5 条里【要试穿的这件衣服】那一段**，其余一个字别动。

## 想试整套搭配？

先把衣柜里的整套搭配**导出成一张平铺图**，再复制 **第 6 条**，
上传 `avatar_base_正面.png` + 搭配导出的 PNG。豆包会识别图里的全部单品，
按真实穿着层次穿到模特身上。其他角度同样替换对应的基准图。

## 三条不能忘

| | |
|---|---|
| 🧷 | 【人物｜锁定块】**逐字复制、不要改写**——改一个字就可能换脸 |
| 📎 | 第 1 步之后，参考图一律传**生成好的基准图**，不要再传原始自拍 |
| 🚫 | 一次只做一个角度，不要让 AI 一次出五个角度 |
| 🪄 | 要上传到衣柜的「上身图」，**先抠成透明 PNG**，否则浅灰底会一起进去 |

---

## 要上传到衣柜的「上身图」？必须多一步

豆包生成的图是**浅灰 #D9D9D9 背景**。衣柜的上身图上传**不会自动去背景**，
它会保留浅灰矩形。要放进衣柜，必须：

1. 先用 AI 抠图（豆包 / rembg / 其他抠图工具）把模特抠成**透明 PNG**；
2. 再在搭配编辑页上传对应角度的「上身图」；
3. 衣柜会把透明区域铺成白色，人物正常显示。

只在豆包里看效果，不需要抠图。

## 完整流程 / 排错

- 五角度顺序、双图输入、豆包操作步骤 → `SKILL.md`
- 六条完整提示词 + 负向词 → `prompts/豆包提示词全集.md`
- 为什么长发要扎起来、皮克斯风为什么不像本人 → `references/形象锁定块.md`
- 生成结果不对怎么排查、自检清单 → `references/避坑与自检.md`

> ⚠️ 13 张原图都是**镜子自拍（左右反向）**、且都是**半身照**。基准图的下半身是 AI 按上半身比例补全的推定结果，不是真实还原；AI 试衣图是搭配示意图，判断不了真实合不合身。
