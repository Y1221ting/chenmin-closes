# 形象锁定块（必须逐字复制，不要改写）

## 一、可直接复制的锁定块

```text
【人物｜锁定块｜逐字复制不要改】
一位二十岁出头的东亚女性 3D 虚拟试衣模特，大学生气质，基于参考照片形象：
柔和的鹅蛋脸，脸颊饱满但下颌线清晰，五官精致协调，白皙通透的肤色；
黑色圆角框眼镜（标志特征，必须保留；镜框中等粗细、比例精致，不要夸张放大或变形）；
黑色长直发 + 齐刘海，发丝顺滑，头发在脑后扎成柔和的低马尾垂在背后，肩颈、锁骨、领口完全露出；
成年女性纤细匀称的身形，约 7 头身，窄肩、腰线自然、四肢修长，站姿舒展；
温柔浅笑，眼神柔和有神，气质清新甜美但不幼态、不儿童化；
自然站立 A-pose：双臂自然下垂微张约 10~15°，手肘微屈，手掌放松、手指自然并拢，双脚并拢，身体直立不歪斜。
```

**使用规则**
- 每条提示词里都是**同一段**，复制粘贴，一个字都不改。
- 改写 = 换脸。改成"漂亮女孩""时尚模特"之类通用描述 = 立刻丢失本人特征。
- 同一次生成**只传一张定稿基准图**当人物参考，不要传多张不同姿态的自拍。
- 基准图定稿后不要覆盖重画；要调整形象另存 v2。

## 二、特征提取依据（13 张本人自拍）

| 部位 | 观察到的真实特征 | 是否进模特 | 处理说明 |
|------|----------------|-----------|---------|
| 眼镜 | 黑色粗框大框眼镜（圆形 / 圆角方形），13 张几乎全有 | ✅ 保留 | **最强辨识特征**；模特镜框做中等粗细、比例精致，不要夸张放大 |
| 脸型 | 圆润娃娃脸 / 鹅蛋脸，脸颊饱满，下巴柔和 | ✅ 保留 | 做成年化、精致化处理：鹅蛋脸、下颌线清晰，不要幼态 |
| 肤色 | 白皙偏暖 | ✅ 保留 | 固定，偏通透干净，不随光照忽深忽浅 |
| 发型 | 黑色长直发及胸，多数带齐刘海（空气 / 薄刘海）；偶尔单侧马尾、双马尾、丸子头 | ✅ 保留刘海 + 黑色长发 | **模特扎柔和低马尾垂在背后**，肩颈领口全露 |
| 身材 | 纤细 petite，窄肩，偏瘦，腰线明显 | ✅ 保留 | 成年女性比例，约 7 头身；不要儿童身材、头大身小 |
| 表情 | 甜美微笑、学生气 | ⚠️ 改温柔浅笑 | 保留甜美气质，但表情要成年、自然，不要幼态 |
| 年龄感 | 二十岁出头的年轻女性 | ✅ 保持成年 | 不要儿童化、Q 版、幼态 |
| 配饰 | 发圈、发夹、珍珠颈链、星星长项链、手表 | ❌ 全部去掉 | 属于可变配饰，会与试穿衣服冲突 |
| 背景 | 灰瓷砖墙、绿色帆船挂画、绿植、镜子、手机 | ❌ 全部去掉 | 全部是干扰项 |

**照片本身的三个坑**
1. **全是镜子自拍，左右是反的**：单侧马尾 / 发夹的位置不要照搬；脸基本对称影响不大。
2. **半身照**：没有一张是全身。基准图的下半身由 AI 按成年女性比例合理补全，所以第 0 条提示词里明确写了「下半身按成年女性比例合理补全为全身，约 7 头身，保持纤细匀称」。补全的下半身是**合理推定，不是真实还原**。
3. **举手机的手**：必须进负向词，否则 AI 会把自拍姿势和手机一起搬进 3D 图。

## 三、三个设计决策的理由

### 1. 为什么长发要扎起来
原《单品图规范》第五节要求看清「领口、肩线、前襟、袖子侧边、下摆」。本人标志性长直发披在身前，恰好盖住领口、肩线、门襟和上衣侧面 —— 试衣图就白做了。
保留辨识度（眼镜 + 齐刘海 + 黑长发）已经足够认出是谁，头发扎低马尾垂在背后，肩颈锁骨领口全露。

### 2. 为什么会换脸
3D 生成每次都重新画一张脸。若每条提示词重新描述人物、或每次传不同的自拍，五角度和不同衣服的模特会越长越不一样。
解法：只做**一次**基准图 → 定稿锁死 → 之后所有图都以它为唯一人物参考 + 锁定块逐字复制。

### 3. 为什么不像本人也要用皮克斯风
皮克斯风必然把脸卡通化、幼态化、美化。能做到「眼镜 + 圆脸 + 刘海 + 纤细身形」的辨识度，做不到照片级相像。
仍然保持皮克斯风，是为了和衣柜里已有的 `*_皮克斯风.png` 单品图统一。
若某天要更相像，需整体换成半写实 3D 数字人，但那样**衣柜里全部单品图也要重做**，否则画风打架 —— 现在不建议动。

> **诚实边界**：AI 试衣图是搭配示意图，会美化身形、会微调衣服细节，不能替代真实上身对版型 / 尺码的判断。别拿它当「合不合身」的结论。
