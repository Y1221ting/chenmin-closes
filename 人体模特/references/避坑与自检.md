# 避坑与自检清单

## 一、常见错误与规避

| # | 错误 | 后果 | 规避写法 |
|---|------|------|---------|
| 1 | **换脸** | 五角度 / 不同衣服的模特越长越不一样 | 只认一张定稿基准图；锁定块逐字复制；不传多张自拍 |
| 2 | **长发盖住衣服** | 领口、肩线、门襟、下摆全被挡，试衣白做 | 「头发扎成低双马尾垂在背后，肩颈、锁骨、领口完全露出」 |
| 3 | **身材被衣服带跑** | 穿羽绒服就变胖、穿宽松款就变壮 | 锁定块写死「纤细窄肩」，加「衣服贴合身形但不改变身材比例」 |
| 4 | **眼镜消失 / 变形** | 丢失最强辨识特征 | 锁定块标为「标志特征，必须保留，镜框粗细与颜色不变」 |
| 5 | **手部畸形 / 举手机的手** | 自拍姿势被搬进 3D 图 | 「手掌放松、五指正常」+ 负向词「多余手指、六指、畸形手、举手机的手」 |
| 6 | **自带配饰** | AI 顺手加项链、发夹、手表 | 单列「不要发圈、发夹、项链、手表等任何配饰」 |
| 7 | **环境残留** | 灰瓷砖墙、绿色帆船挂画、绿植、镜子出现 | 负向词全列；背景写死纯色浅灰 |
| 8 | **镜像 / 文字反向** | 自拍是镜像，衣服字母反了 | 「不要镜像文字」「文字按正常阅读方向」 |
| 9 | **落地阴影 / 投影** | 贴边连通的阴影后期切不干净 | 源头要求「无落地阴影、无投影、无接触暗影、无灰色投影块」 |
| 10 | **浅色高光被误删** | 抠图把高光、绒毛删成白斑 | 浅色一律用 AI 抠图（rembg / u2net 类），**不要用亮度 / 灰度阈值** |
| 11 | **前后方向拧转** | 后 135° / 背面出现正脸、刘海朝前 | 「前后方向一致，不要把正面特征拧到后侧」 |
| 12 | **一次出五个角度** | AI 顾此失彼，五个都变形 | 一次只做一个角度 |
| 13 | **每次重画基准图** | 旧试衣图与新模特对不上 | 基准图定稿后存固定文件名，后续只读不重生成 |
| 14 | **背景用纯白** | 本人常穿米白 / 浅粉 / 冰蓝，衣身糊进背景 | 统一浅灰 `#D9D9D9` |
| 15 | **直接上传灰底图到衣柜** | 衣柜上身图会保留灰色矩形 | 先 AI 抠成透明 PNG，再上传到衣柜 |
| 16 | **整套搭配少一件 / 多一件** | 生成的搭配和衣柜里的不一致 | 用衣柜导出的整套搭配图当参考图 2，提示词写死「不遗漏、不新增」 |

## 二、出图后自检清单

**人物一致性（最关键）**
- [ ] 长相 / 脸型五张完全一致，没换脸、没变成网红脸
- [ ] 黑色粗框大框圆角眼镜在，且镜框粗细、颜色、位置一致
- [ ] 齐刘海在；头发扎低双马尾垂在背后，没有披在胸前
- [ ] 肩颈、锁骨、领口完全露出，没有被头发遮住
- [ ] 纤细窄肩、腰线明显；没有因为外套宽松被画胖
- [ ] 中性自然表情，没有夸张笑 / wink / 嘟嘴
- [ ] A-pose 一致：双臂微张约 15°、双脚并拢、身体直立不歪斜

**画面**
- [ ] 五角度齐全，尺寸一致（3:4，1330×1773 或平台最接近竖版）
- [ ] 全身入镜，头顶 / 脚底各留约 5% 空白，没有裁切头脚
- [ ] 纯色浅灰背景 #D9D9D9，平整无渐变
- [ ] 无落地阴影 / 投影 / 接触暗影 / 灰色投影块
- [ ] 手指数量正常、无畸形手、无举手机的手
- [ ] 无配饰、无手机、无镜子、无瓷砖墙、无挂画绿植、无多余人物
- [ ] 无文字 / logo / 标语 / 吊牌 / 水印 / 边框、无镜像文字

**试衣图额外检查**
- [ ] 只换了那一件外层衣服，基础打底和人物均未变
- [ ] 衣服自然贴合身形、有合理褶皱垂坠，不像贴纸
- [ ] 衣服结构（领口、门襟、盘扣、口袋、下摆）没有被头发遮住
- [ ] 衣服版型、颜色、面料与参考图一致，没被 AI 改款
- [ ] 侧面 / 背面没有凭空多出的贴袋、贴标、印花、徽章
- [ ] 背面纯色简洁，未复制正面图案、未出现正脸
- [ ] 整套搭配没有漏掉或新增单品，外套 / 内搭 / 鞋包层次正确

**上传到衣柜「上身图」前（必做）**
- [ ] 已把模特图抠成**透明 PNG**（浅灰背景不能直接上传）
- [ ] 导出为 RGBA（alpha 0–255）
- [ ] 边缘无灰边、无白斑、无残留阴影
- [ ] 浅色衣物高光与绒毛保留完整
- [ ] 上传后衣柜显示为白底人物，没有灰色矩形

## 三、命名与资产约定

| 类型 | 命名 |
|------|------|
| 模特基准图 | `avatar_base_{正面\|左前45\|左侧面\|左后135\|背面}.png` |
| 试衣效果图 | `tryon_{衣服名}_{角度}.png` |
| 衣服参考图 | 复用衣柜已有 `*_皮克斯风.png` 单品图 |

- 文件名用**英文**（中文文件名在预览面板会被百分号编码打不开）。
- 基准图定稿后**不要覆盖**；要调整形象另存 `avatar_base_v2_*.png`。
